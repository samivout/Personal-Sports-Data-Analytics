# Personal Sports Data Analytics

A self-hosted application for collecting, processing and analyzing personal sports-performance and physiological data.

## Purpose

The project aims to provide a flexible environment for exploring personal training data beyond conventional fitness tracking and reporting tools.

The primary objective is to identify trends, statistical relationships and deviations in training and physiological measurements over time.

## Planned scope

- Integration with the Polar Flow ecosystem through the Polar AccessLink API.
- Automated retrieval and local storage of training data.
- Historical data import and normalization.
- Statistical analysis of heart rate, speed, distance and other available measurements.
- Comparison of training sessions and activity types.
- Longitudinal trend analysis and anomaly detection.
- Interactive visualizations and exploratory analysis.

## Architecture

The intended architecture consists of a lightweight self-hosted web application for API authorization and data retrieval, a local analytical database, and a Python-based analysis environment.

## Intended use

This is a personal, single-user project intended exclusively for analyzing the author's own sports and physiological data. It is not intended to provide services to third parties or compete with existing fitness platforms.

## Project status

Early development. Features and architecture are subject to change. Currently waiting on access to the Polar AccessLink API and start of planning and development.
